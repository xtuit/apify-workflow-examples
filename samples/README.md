Workday's full source job descriptions are intentionally omitted from these public excerpts. The live Actor can return descriptions when enabled and successfully fetched. The technology example retains a small amount of public matching evidence. Collection timestamps remain the original timestamps.

The client tests use separate synthetic in-memory fixtures to exercise failures and edge cases. No customer data, tokens, account financial records, complete run metadata or private Actor source is included in these samples.
